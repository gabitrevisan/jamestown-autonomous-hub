## 🔗 Integração
Este módulo lê o arquivo `vision_diagnosis.json` gerado pelo módulo de Visão Computacional para embasar suas respostas.

## 🚀 Como Executar
1. Configure o arquivo `.env` com sua `GEMINI_API_KEY`.
2. Instale as dependências: `pip install requests`
3. Inicie o assistente: `python assistant.py`
